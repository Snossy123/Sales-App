## 1. مقدمة

### ما هو النظام؟

نظام GPS للمبيعات يدير دورة العمل اليومية: العملاء، التعاقدات (أجهزة وخدمات وإكسسوارات)، الأقساط، المخزون، المراجعة، التحصيل، والترشيحات، مع وحدات للمحاسبة والموارد البشرية والدعم حسب صلاحية كل مستخدم.

هذا ليس تطبيق تتبّع أسطول على الخريطة. «GPS» هنا يعني **بيع أجهزة التتبع وتركيبها وتحصيل اشتراكاتها**.

### الواجهة

- الواجهة **عربية** واتجاه الصفحة من اليمين لليسار (RTL).
- القوائم الجانبية تظهر حسب **دورك وصلاحياتك**؛ إن لم تظهر لك صفحة معيّنة فهذا متوقع وليس خللاً.
- من الشريط العلوي اختر **الفرع النشط** قبل إنشاء تعاقدات أو عرض بيانات مرتبطة بفرع.
- على الشاشات الصغيرة يوجد شريط تنقل سفلي سريع (الرئيسية / المخزون / المبيعات / التحصيل / التقارير حسب الدور).

### الأدوار الشائعة

| الدور | ماذا يرى عادةً |
| --- | --- |
| مدير النظام | معظم الشاشات وإدارة المستخدمين وإعدادات النظام |
| مدير الإدارة | لوحة الإدارة، فروع إدارته، المخزون والتعاقدات والمراجعة والتحصيل ضمن نطاقه |
| مدير الفرع | فرعه والمخزون والتعاقدات والمراجعة والتحصيل ضمن الفرع |
| المبيعات | مهمة اليوم، تعاقدات، عملاء، موزعين، مخزون الفرع |
| المراجعة | مراجعة التعاقدات والتحصيلات والمصروفات والتقييمات وقائمة المشاكل |
| التحصيل | تحصيل الأقساط وسجل المدفوعات والعملاء |
| مركز الاتصال | التحصيلات الخارجية |
| مبيعات CRM | مجموعة **المبيعات**: الترشيحات والمتابعات والتقارير |
| المحاسبة | المحاسبة والتقارير |
| الموارد البشرية | الموظفون والحضور والرواتب |
| الدعم الفني | مهامي / إكمال التركيب |

مدير الإدارة ومدير الفرع لا يملكان عادةً **استرداد دفعة** ولا **إدارة الأدوار** على مستوى المؤسسة.

## 2. تسجيل الدخول والواجهة

### متى تستخدمها

عند بدء العمل اليومي أو بعد انتهاء الجلسة.

### الخطوات

1. افتح رابط النظام الذي زوّدك به مدير النظام.
2. أدخل **البريد الإلكتروني** و**كلمة المرور**. بجانب كلمة المرور زر **إظهار كلمة المرور**؛ بعد الإظهار يصبح **إخفاء كلمة المرور**.
3. بعد الدخول تظهر **لوحة التحكم** أو الصفحة الافتراضية حسب دورك (مثلاً المبيعات → مهمة اليوم، المراجع → مراجعة التعاقدات، المحصّل → تحصيل الأقساط).
4. لتسجيل الخروج استخدم **تسجيل الخروج** أسفل القائمة الجانبية.

### الشريط العلوي

- **اختيار الفرع:** القائمة المنسدلة للفرع — اختره قبل التعاقد أو التحصيل.
- **الإشعارات:** أيقونة الجرس. بعض الإشعارات تفتح حركة جهاز بانتظار التأكيد (`/inventory/movements/{رقم}`). يمكن تعليم الكل كمقروء.
- **الحساب:** الحرف الأول من اسمك يفتح صفحة الحساب (`/profile`): الصورة، سجل الموظف المرتبط، تقدّم هدف المبيعات إن وُجد. يظهر تحت الاسم الدور ونطاق البيانات.
- **طي القائمة:** زر القائمة يضيق الشريط الجانبي لتوسيع مساحة العمل.

### اختصار تعاقد جديد

إن كان دورك مبيعات أو أدمن يظهر زر **تعاقد جديد** أسفل القائمة الجانبية. نقطة صغيرة على الزر تعني وجود **مسودة غير مكتملة**.

### مسودات غير مكتملة

شريط أعلى الصفحة: «عندك إجراء غير مكتمل». اضغط **متابعة** لإكمال التعاقد أو بيع الإكسسوارات أو تعاقد الخدمات، أو تجاهل المسودة بعد التأكيد.

### مهمة اليوم ولوحة التحكم

- **مهمة اليوم** (`/sales/mission`) — للمبيعات: صناديق **لازم تتكلم معاهم**، **معاينات**، **جاهزين للتعاقد**، **متأخر (≥ يومين)**، **أولوية VIP**. الضغط على بطاقة يفتح صفحة العميل.
- **لوحة التحكم** (`/`) — ملخص حسب الدور: مؤشرات، فلاتر الفترة (يوم/أسبوع/شهر) والفرع، أقساط متأخرة، وروابط سريعة. للأدمن تظهر أيضاً رسوم المخزون.

### على شاشات التعاقد

- أعلى شاشة POS توجد تبويبات: **تعاقد جديد (أجهزة)** / **تعاقد خدمات** / **بيع إكسسوار**.
- زر **مسح البيانات** يفرّغ النموذج الحالي بعد التأكيد.
- زر **تعاقداتي** (ليس في الشريط الجانبي) يفتح `/invoices/mine` في تبويب جديد: عقودك أنت فقط.
- شريط مخزون الفرع يظهر أعلى المحتوى عند الحاجة.

### ملاحظات / أخطاء شائعة

- إن ظهرت رسالة بيانات غير صحيحة: تأكد من البريد وكلمة المرور وحالة الحساب مع المدير.
- إن لم يظهر فرع في القائمة العلوية: قد لا يكون مربوطاً بحسابك — راجع مدير النظام.
- اختر الفرع الصحيح قبل التعاقد أو التحصيل حتى لا تُسجَّل البيانات على فرع خاطئ.

## 3. الإدارة

### متى تستخدمها

عند إعداد الإدارات والفروع والأقسام لأول مرة أو عند التوسع، ومتابعة نشاط اليوم.

### من القائمة

**الإدارة**

- **الإدارات** (`/departments`) — لمدير النظام
- **كل الفروع** أو **فروع الإدارة** (`/branches`)
- **الأقسام** (`/sections`)
- **لوحة الإدارة** (`/gps/management`) — لمدير الإدارة: مؤشرات، اتجاه المبيعات، حالة الأجهزة
- **البيان اليومي** (`/daily-reports`) — ملخص نشاط اليوم (مبيعات / تحصيلات)؛ للطباعة: `/daily-reports/{رقم}/print`

### إضافة إدارة

1. من **الإدارة ← الإدارات**.
2. اضغط إضافة إدارة.
3. أدخل الاسم بالعربية والبيانات المطلوبة ثم احفظ.

### إضافة فرع

1. من **الإدارة ← كل الفروع** (أو فروع الإدارة).
2. اضغط إضافة فرع.
3. اربط الفرع بالإدارة المناسبة واملأ الاسم والكود ثم احفظ.

### إضافة قسم

1. من **الإدارة ← الأقسام**.
2. اضغط إضافة قسم.
3. اختر **الفرع** ثم أدخل اسم القسم بالعربية واحفظ.

### ملاحظات

- القسم يتبع فرعاً، والفرع يتبع إدارة.
- حذف إدارة أو فرع قد يُرفض إذا وُجدت بيانات مرتبطة (مخزون، تعاقدات، موظفون).

## 4. الآعدادات — المستخدمون والأدوار

مجموعة القائمة اسمها **الآعدادات** (كما تظهر في الشريط الجانبي).

### متى تستخدمها

عند إنشاء حسابات للموظفين أو تعديل صلاحياتهم أو مراجعة السجلات.

### من القائمة

- **الآعدادات ← المستخدمون** (`/admin/users`)
- **الآعدادات ← الأدوار** (`/admin/roles`) ثم صلاحيات دور معيّن (`/admin/roles/{رقم}/permissions`)
- **الآعدادات ← سجل التدقيق** (`/admin/activity-log`)
- **الآعدادات ← سلة المهملات** (`/admin/trash`) — استرجاع أو حذف نهائي
- **الآعدادات ← إدارة الأسئلة** (`/admin/faq`)
- **الآعدادات ← ملاحظات المستخدمين** (`/admin/feedback`)
- **الآعدادات ← إعدادات النظام** (`/admin/settings`) — لمدير النظام الأعلى فقط (شعار المؤسسة، حد أدنى للمقدم، قوالب الرسائل، …)
- يمكن أيضاً إنشاء مستخدم من **الموارد البشرية ← الموظفون** (تبويب مستخدم) لمن لديه صلاحية إدارة المستخدمين.

### إضافة مستخدم

1. من **الآعدادات ← المستخدمون**.
2. اضغط **مستخدم جديد**.
3. أدخل: الاسم، البريد، كلمة المرور (8 أحرف على الأقل).
4. اختر **الإدارة** و**الفرع الأساسي** و**القسم** إن لزم.
5. حدّد **الفروع المسموحة** إن كان الموظف يتنقل بين فروع (اتركها فارغة لاستخدام كل فروع الإدارة حسب سياسة النظام).
6. اختر **الأدوار** ثم احفظ.

### الأدوار والصلاحيات

1. من **الآعدادات ← الأدوار**.
2. راجع الأدوار الجاهزة أو أنشئ دوراً مخصصاً (حسب صلاحيتك).
3. افتح **صلاحيات الدور** لتفعيل أو إيقاف مفاتيح مثل: تعاقد جديد، اعتماد مراجعة، تحصيل أقساط، إدارة مشاكل العقد.
4. عيّن الدور للمستخدم من شاشة المستخدمين.

### سجل التدقيق وسلة المهملات

- **سجل التدقيق:** من نفّذ ماذا ومتى (إنشاء/تعديل/حذف). استخدمه عند خلاف على عقد أو دفعة.
- **سلة المهملات:** سجلات محذوفة حذفاً ناعماً (عملاء، عقود، **أقساط**، …). **استرجاع** يعيدها، **حذف نهائي** لا يمكن التراجع عنه.
- لاسترجاع قسط محذوف: **الآعدادات ← سلة المهملات** ← فلتر النوع **قسط** ← **استرجاع**. الاسترجاع يتم من هنا وليس من شاشة التحصيل.

### ملاحظات / أخطاء شائعة

- مدير الإدارة قد لا يستطيع تعيين أدوار عليا (مثل صلاحيات على مستوى المؤسسة كلها).
- بدون فرع/قسم قد لا يُنشأ سجل موظف تلقائياً مرتبط بالحساب.
- لا يمكن حذف حسابك الحالي وأنت مسجّل به.

## 5. العملاء والموزعين

### 5.1 العملاء

#### من القائمة

**العملاء** (`/customers`) — بند مستقل في الشريط (ليس داخل مجموعة).

#### إضافة عميل

1. من قائمة العملاء اضغط الإضافة، أو افتح `/customers/add`.
2. أدخل **اسم العميل** (مطلوب).
3. أدخل **رقم الهاتف** الأول (مطلوب) ويمكن إضافة أرقام إضافية مع تسمية كل رقم (شخصي، زوجة، …).
4. اختياري: الرقم القومي، العنوان، العلامة المميزة.
5. اختر **ضامن** أو **بدون ضامن**. إن اخترت ضامناً أدخل اسمه وهاتفه على الأقل.
6. أرفق مستندات إن لزم من قسم المرفقات.
7. اضغط **حفظ العميل** — ستنتقل لصفحة تفاصيل العميل.

#### قائمة العملاء وتعديلهم

1. ابحث بالاسم أو فلتر الحالة.
2. افتح العميل للتفاصيل أو التعديل (هواتف، ضامن، مرفقات، تعاقدات مرتبطة).

#### صفحة تفاصيل العميل

تبويبات شائعة: البيانات، المكالمات، العقود، المدفوعات، التركيبات، الشكاوى، الضمان، الترشيحات، التقييم، الملفات.

من تبويب العقود: تفاصيل العقد، طباعة العقد، **تحويل للمشاكل** إن انطبق.

للمحصّل: إجراءات التحصيل تشمل **رسيت متأخر** — تفعيلها يمنع دخول العميل لبوابة العميل حتى إلغاء الحالة.

### 5.2 الموزعين

#### من القائمة

**الموزعين** (`/distributors`) — بند مستقل.

#### الخطوات

1. افتح قائمة الموزعين.
2. أضف موزعاً جديداً بالكود والاسم والهاتف ونسبة العمولة وربطه بالفرع.
3. الموزع يظهر لاحقاً في شاشة التعاقد وعند احتساب العمولة، مع سجل عمولة في تفاصيل الموزع.

### ملاحظات / أخطاء شائعة

- لا يمكن حفظ عميل بدون اسم وهاتف.
- إن ظهر خطأ صلاحية: دورك لا يملك إضافة عملاء — استخدم حساب مبيعات أو أدمن.
- ربط العميل بموزع يؤثر على العمولة عند التعاقد.

## 6. قسم التعاقدات

### متى تستخدمها

عند بيع جهاز GPS أو خدمة أو إكسسوارات مرتبطة بعقد للعميل.

قائمة تجريب يدوي (UAT) لتسليم العميل: [`uat-contracts-ar.md`](uat-contracts-ar.md).

### من القائمة

**قسم التعاقدات**

- تعاقد جديد (`/pos`)
- تعاقد خدمات (`/pos/services`)
- بيع إكسسوارات (`/sales/accessories`)
- دليل الأسعار (`/pricing/catalog`)
- العروض (`/pricing/promotions`)
- تجديد الاشتراكات (`/review/subscription-renewals`) — يظهر أيضاً للمراجع
- طلب مصروف (`/expenses/new`) — للأدمن عادة

المسار `/sales/maintenance` يحوّل تلقائياً إلى **تعاقد خدمات**.

### 6.1 شاشة التعاقد المشتركة

1. تأكد من اختيار **الفرع** من الشريط العلوي والمخزن المناسب إن طُلب.
2. استخدم التبويبات أعلى الصفحة للتنقل بين أجهزة / خدمات / إكسسوار.
3. **مسح البيانات** يفرّغ النموذج الحالي فقط (بعد التأكيد).
4. إن خرجت قبل الحفظ تُحفظ **مسودة**. من الشريط العلوي: متابعة أو تجاهل.
5. **تعاقداتي** لعرض عقودك أنت.

### 6.2 تعاقد أجهزة — أنواع الخدمة

من **قسم التعاقدات ← تعاقد جديد**. أزرار **نوع الخدمة**:

| النوع | متى تستخدمه | ملاحظات |
| --- | --- | --- |
| **تعاقد جديد** | بيع جهاز من مخزون الشركة | الوحدة من المخزن مطلوبة؛ لا إدخال يدوي للسيريال بدل المخزون |
| **تجديد اشتراك** | تجديد جهاز موجود | اختر التعاقد المراد تجديده. السنوي بسعر من الإعدادات؛ مدى الحياة نسبة من كاش الاشتراك السنوي (غالباً 25%) |
| **جهاز خارج الشركة** | جهاز لم يُبَع من الشركة ويُضاف للنظام | يُسمح بإدخال السيريال يدوياً |
| **نقل ملكية** | نقل الجهاز من عميل إلى آخر | اختر العقد المصدر ثم العميل الجديد. العقد المنقول مسبقاً لا يُختار مرة ثانية |

### 6.3 تعاقد أجهزة — الخطوات

1. اختر **نوع الخدمة**.
2. اختر **العميل** (ابحث بالاسم أو الهاتف). إن لم يوجد أنشئه أولاً من العملاء.
3. اختر **الموزع** و/أو **موظف المبيعات** حسب سياسة الفرع.
4. أضف الجهاز/الأجهزة من المخزون المتاح (أو إدخالاً يدوياً لأنواع غير «تعاقد جديد»).
5. أكمل بيانات التركيب إن لزم (سيريال، شريحة، لوحة، فني، مركبة…).
6. إن ظهر حقل **رسوم انتقال**: أدخله مرة واحدة. قد لا يُضاف على «قيمة التعاقد» المعروضة للمبيعات حسب إعداد النظام.
7. اختر طريقة الدفع لكل جهاز:
   - **كاش** وموعد السداد: **فوري** / **شهر** / **شهرين** / **3 شهور**.
   - **مقدم جزئي**: مبلغ أقل من الإجمالي؛ الباقي يُستحق حسب الجدول.
   - **تقسيط**: قيمة القسط والمقدم؛ يُحسب عدد الأقساط. مجموع الأقساط يجب ألا يتجاوز إجمالي التعاقد. حدّد تاريخ أول استحقاق.
8. راجع الإجمالي ثم احفظ/أكّد التعاقد. يدخل عادةً **مراجعة**.
9. اطبع العقد من شاشة التفاصيل: عقد تقسيط، عقد نقل ملكية، أو عقد خدمة حسب النوع.

### 6.4 تعاقد خدمات

1. من **قسم التعاقدات ← تعاقد خدمات** (أو تبويب تعاقد خدمات).
2. فعّل شريحة واحدة أو أكثر:
   - **تجديد اشتراك سنوي**
   - **جهاز خارج الشركة**
   - **فك** / **تركيب** / **برمجة** / **سوفت**
3. أكثر من شريحة معاً ينتج نوع عقد **خدمات مجمّعة**.
4. اختر العميل والبنود والأسعار وطريقة الدفع (كاش، تقسيط، أو توزيع مختلط إن ظهر في الشاشة).
5. لبعض بنود الفك يظهر **تسليم عهدة الجهاز**.
6. تجديد مدى الحياة داخل المسار المختلط قد يُرفض — استخدم مسار الأجهزة أو سياسة الفرع.
7. احفظ. بعد الإكمال يمكن طباعة عقد الخدمة من `/invoices/{رقم}/service-contract`.

### 6.5 بيع إكسسوارات

قبل البيع يجب وجود أصناف في **المخزون ← كتالوج الإكسسوارات** وكميات في **مخزون الإكسسوارات** (وباكدجات إن لزم).

1. من **قسم التعاقدات ← بيع إكسسوارات**.
2. ابحث واختر **العميل** (أو أنشئه من النافذة إن توفرت).
3. اختر **الفرع** و**المخزن**.
4. أضف إكسسوارات أو باكدجات للكمية والسعر.
5. راجع السلة ثم أكمل البيع. كمية أكبر من المتاح تُرفض.
6. يمكن حفظ مسودة مثل باقي شاشات POS.

### 6.6 دليل الأسعار والعروض

1. من **قسم التعاقدات ← دليل الأسعار**: عدّل سعر الكاش/التقسيط للجهاز أو الخدمة. السعر المحدَّث يظهر في التعاقد الجديد.
2. من **قسم التعاقدات ← العروض**: أنشئ عرضاً بتاريخ بداية ونهاية. العرض الساري يُطبَّق على البنود أو الإجمالي حسب السياسة؛ العرض المنتهي لا يُطبَّق.

### 6.7 تجديد الاشتراكات (الطابور)

1. من **قسم التعاقدات ← تجديد الاشتراكات** (أو يظهر للمراجع من نفس المسار).
2. تظهر قائمة العملاء الذين يحتاجون تجديد اشتراك سنوي للتواصل معهم.
3. اضغط بدء التجديد / رابط الصف: تُفتح `/pos` بنوع **تجديد اشتراك** وبيانات السطر معبأة مسبقاً.

### 6.8 طلب مصروف

1. من **قسم التعاقدات ← طلب مصروف**.
2. أدخل المبلغ والسبب والمرفقات إن لزم ثم أرسل.
3. يظهر الطلب في **المراجعة ← مراجعة المصروفات** للاعتماد.

### 6.9 الخدمات ونماذج العقود (للمدير)

مجموعة **الخدمات** (منفصلة عن قسم التعاقدات):

- **الخدمات ← الخدمات** (`/services`) — كتالوج الخدمات (فك، تركيب، برمجة، سوفت، تجديد…).
- **الخدمات ← إضافة خدمة** (`/services/add`).
- **الخدمات ← نماذج العقود** (`/contract-templates`) — معاينة قوالب الطباعة (تعاقد، تجديد كاش/قسط، نقل ملكية، …).

### ملاحظات / أخطاء شائعة

- «الوحدة ليست في المخزن المحدد»: اختر المخزن الذي توجد فيه الوحدة فعلياً.
- «مجموع الأقساط يتجاوز الإجمالي»: قلّل قيمة القسط أو عدد الأقساط.
- بدون عميل أو بدون مخزون متاح لن يكتمل التعاقد الجديد.
- «يجب اختيار التعاقد المراد تجديد اشتراكه»: اختر العقد المصدر قبل الحفظ.
- بعد الحفظ قد يدخل التعاقد **مراجعة** قبل الاعتماد النهائي حسب إعدادات النظام.
- دور التحصيل أو CRM فقط لا يرى قسم التعاقدات — هذا متوقع.

## 7. المراجعة

### متى تستخدمها

للتحقق من صحة التعاقدات والتحصيلات والمصروفات قبل الاعتماد النهائي، ولتقييم خدمة العملاء.

### من القائمة

**المراجعة**

- مراجعة التعاقدات (`/invoices/review`)
- مراجعة التحصيلات (`/review/collections`)
- مراجعة المصروفات (`/review/expenses`)
- كل التعاقدات (`/invoices`)
- تقييم العملاء (`/review/evaluation-queue`)
- أسئلة التقييم (`/review/evaluation-questions`)

تجديد الاشتراكات وطلب مصروف موجودان تحت **قسم التعاقدات**.

### مراجعة تعاقد

1. من **المراجعة ← مراجعة التعاقدات**.
2. ابحث برقم العقد أو العميل. استخدم فلتر **نوع الخدمة**: تعاقد جديد / تجديد اشتراك / نقل ملكية / جهاز خارج الشركة / خدمات مجمّعة.
3. افتح تعاقداً بانتظار المراجعة.
4. تحقق من العميل والأجهزة والدفع.
5. اضغط الاعتماد (قد يظهر النص حسب النوع: **تأكيد وإرسال الأقساط**، **اعتماد تجديد اشتراك**، **اعتماد نقل ملكية**، **اعتماد جهاز خارج الشركة**، **اعتماد خدمات مجمّعة**) أو **رفض** مع سبب.

### تعديل العقد

- **المبيعات** يمكنها التعديل ما دام العقد **قيد المراجعة**. بعد الاعتماد يُرفض تعديل المبيعات.
- **المراجع** يمكنه التعديل بعد الاعتماد حسب الشاشة والصلاحية.
- عقد **مرفوض** بعد تعديل المبيعات وحفظه يعود عادةً **قيد المراجعة**.

### كل التعاقدات وتعاقداتي

- **المراجعة ← كل التعاقدات**: فلاتر الحالة وتاريخ الدفع والبحث والترقيم اللوني (أحمر = بانتظار المراجعة، أخضر = معتمد). من عمود الإجراءات: تفاصيل، طباعة، تحويل للمشاكل، استرجاع مختصر.
- **تعاقداتي** (`/invoices/mine`): من زر تعاقداتي في شاشات POS — عقود منشئها أنت فقط.

### مراجعة التحصيلات

1. من **المراجعة ← مراجعة التحصيلات**.
2. افتح الدفعة الخارجية أو تحصيل القسط بانتظار الاعتماد.
3. اعتمد أو ارفض مع سبب. التحصيل غير المعتمد قد لا يُغلق القسط نهائياً حسب السياسة.

### مراجعة المصروفات

1. من **المراجعة ← مراجعة المصروفات**.
2. افتح الطلب، راجع المبلغ والمرفقات، ثم اعتمد أو ارفض.

### تقييم العملاء

1. من **المراجعة ← أسئلة التقييم**: أضف أو عدّل الأسئلة التي تظهر للمراجع.
2. من **المراجعة ← تقييم العملاء**: افتح سجلاً في الطابور وسجّل التقييم على العقد/العميل.

### ملاحظات

- ألوان الصفوف غالباً: أحمر = بانتظار المراجعة، أخضر = معتمد.
- استخدم فلاتر التاريخ والحالة ونوع الخدمة لتضييق القائمة.

## 8. قسم الاقساط

اسم المجموعة في القائمة: **قسم الاقساط**.

### متى تستخدمها

لتحصيل الأقساط المستحقة ومتابعة المدفوعات والعملاء المتعثرين.

### من القائمة

- تحصيل الأقساط (`/installments`)
- سجل المدفوعات (`/payments`)
- التحصيلات الخارجية (`/call-center/collections`) — لمركز الاتصال
- حسابات التحويل (`/admin/collection-accounts`) — للأدمن

### تحصيل قسط

1. من **قسم الاقساط ← تحصيل الأقساط**.
2. اختر بطاقة الفرع (تظهر أعداد المتأخر والمستحق قريباً).
3. بطاقات اليوم تفلتر القائمة أيضاً: **تأجيلات**، **تم الدفع اليوم**، **متابعة اليوم**، **لم يتم الرد**، **لم يتم التواصل**.
4. الفلاتر:
   - **فلتر العقود:** كل العقود / متأخرة / مستحقة / قادمة / تصالح مفتوح.
   - **حالة التحصيل:** تم الرد / تأجيلات / مواعيد جديدة للدفع / لم يتم الرد / لم يتم التواصل.
   - **المحصل:** كل المحصلين أو غير معيَّن أو محصّل بعينه.
   - **حالة القسط** و**الترتيب** (حسب الأولوية أو ميعاد التذكير).
5. ابحث عن العميل أو رقم التعاقد أو الهاتف.
6. كل تعاقد يظهر ببطاقة القسط الحالي مع **تحصيل**، و**تصالح** إن كان متأخراً، و**لم يتم الرد** إن لم تكن الحالة مسجّلة مسبقاً.
7. من نفس البطاقة يمكن:
   - **عرض جميع الأقساط المستحقة** — الأقساط غير المسددة لهذا التعاقد.
   - **عرض جميع الأقساط** — الجدول الكامل. هنا تظهر أعمدة **تاريخ السداد** و**طريقة الدفع** (نقدي / محفظة / انستا / تحويل بنكي / رصيد موزع). القسط غير المسدد يظهر `—` في هذين العمودين.
8. إجراءات الصف في الجدول: **تحصيل** و**تصالح** فقط. لا يوجد حذف قسط من شاشة التحصيل.
9. عند التحصيل يمكن اختيار **ربع المتبقي** أو **نصف المتبقي** أو **كامل المتبقي**، أو إدخال مبلغ. طريقة الدفع:
   - **نقدي**
   - **محفظة** / **انستا** / **تحويل بنكي** — اختر حساب التحويل ورقم المرسل إن طُلب
10. من **المزيد من الإجراءات**:
    - **متابعة التحصيل:** ميعاد المتابعة ثم **حفظ متابعة التحصيل**. **سجل متابعة العقد** يعرض ما سُجّل سابقاً.
    - **تعليق التعاقد** بسبب **لم يُركّب بعد** أو **استلام الجهاز** أو **العربية محبوسة**.
    - جزء من رصيد الموزع، تعديل تاريخ الاستحقاق التالي، **تأجيل**، أو تعديل تواريخ أقساط لاحقة.
11. إن ظهرت **تسوية/تصالح**: أغلق التصالح المفتوح قبل التحصيل، أو افتح تصالحاً للمتأخر بصلاحية `تصالح الأقساط`.
12. أكّد التحصيل. اطبع الإيصال من `/payments/{رقم}/receipt`.

### سجل المدفوعات والاسترداد

1. من **قسم الاقساط ← سجل المدفوعات**.
2. الفلاتر: الفترة (**يوم** / **أسبوع** / **شهر** / **سنة** / **مخصص**)، **كاش أو تحويل**، **طريقة الدفع**، **الفرع**، النوع (**كل المدفوعات** / **أوامر الدفع**)، والحالة (**نشط** / **مُسترد**).
3. راجع الدفعات بالتاريخ والعميل واطبع الإيصال.
4. عند الحاجة استخدم **استرداد** لإلغاء دفعة (يحدّث رصيد القسط). الاسترداد صلاحية خاصة وقد تكون ممنوعة على مدير الإدارة/الفرع.

### التحصيلات الخارجية

من **قسم الاقساط ← التحصيلات الخارجية** لمتابعة وتحصيل خارج الفرع (تحويلات / محافظ حسب الإعداد). بعد التسجيل قد تحتاج **مراجعة التحصيلات**.

### حسابات التحويل

من **قسم الاقساط ← حسابات التحويل**: أضف حسابات المحفظة والانستا والبنك المستخدمة عند التحصيل غير النقدي. عطّل الحساب غير المستخدم حتى لا يظهر في شاشة التحصيل.

### بوابة العميل من التحصيل

من صفحة العميل، المحصّل يمكنه **تفعيل رسيت متأخر** لمنع دخول العميل للبوابة، أو إلغاء الحالة لاحقاً.

### ملاحظات / أخطاء شائعة

- قد يُرفض التحصيل إن وُجدت **تسوية مفتوحة** على القسط — أغلق التسوية أولاً.
- الأقساط المعلّقة قد تمنع التحصيل حتى الاستئناف.
- تأكد من حسابات التحويل النشطة قبل استلام تحويلات خارجية.
- بعد اعتماد التعاقد وإكمال التركيب تُحسب مواعيد الأقساط من **تاريخ التنفيذ** إن انطبق.
- لا يُحذف قسط من جدول التحصيل. إن وُجد قسط محذوف سابقاً يُسترجع من سلة المهملات (انظر القسم 4).

## 9. قسم المشاكل

### متى تستخدمها

عند إلغاء تعاقد، استرجاع جهاز، استبدال، أو فتح مهمة دعم على عقد معتمد.

### من القائمة

**قسم المشاكل ← قائمة المشاكل** (`/problems`)

يظهر زر **تحويل للمشاكل** أيضاً من:

- **تفاصيل العقد** (`/contracts/{رقم_العقد}`)
- **المراجعة ← كل التعاقدات** (أو تعاقداتي) في عمود الإجراءات
- **صفحة العميل ← التعاقدات** بجانب تفاصيل العقد وطباعة العقد

زر **استرجاع** المختصر يفتح نفس المعالج مباشرة على نوع الاسترجاع.

### متى يظهر المعالج؟

يظهر زر **تحويل للمشاكل** فقط إذا تحقق كل الآتي:

- العقد **معتمد** (بعد المراجعة).
- حالة التعاقد **ساري**.
- حسابك يملك صلاحية **إدارة مشاكل العقد**.

### أنواع المشكلة

| النوع | متى تستخدمه | ماذا يحدث تقريباً |
| --- | --- | --- |
| **دعم فني** | عطل أو زيارة فني بدون فك العقد | تُنشأ مهمة دعم على العقد وتظهر في الدعم الفني |
| **استرجاع** | بعد التركيب أو عندما لا يصلح الإلغاء | إرجاع الجهاز للمخزون وأمر دفع/رسوم فك إن لزم |
| **استبدال** | تبديل الجهاز بجهاز آخر من مخزون الفرع | استبدال الوحدة مع استمرار العقد |
| **إلغاء التعاقد** | **فقط قبل تنفيذ الفني للتركيب** | إلغاء المهمة ورجوع الجهاز ورد المقدم |

إذا نفّذ الفني التركيب، النظام يرفض **إلغاء التعاقد** ويجب استخدام **استرجاع**.

### الخطوات المشتركة

1. افتح العقد من تفاصيله، أو من **كل التعاقدات**، أو من **تعاقدات العميل**، أو من **قائمة المشاكل**.
2. اضغط **تحويل للمشاكل**.
3. اختر النوع واكتب **السبب** وأكمل الخطوات حسب النوع أدناه.

### دعم فني

1. اختر **دعم فني**.
2. أدخل السبب والملاحظات.
3. حدّد الموظف الفني وموعد الزيارة إن طُلب.
4. أكمل. تظهر المهمة في **الدعم الفني ← مهامي** للفنّي المعيَّن، وفي **إدارة المهام** للأدمن.

### استرجاع

1. اختر **استرجاع** (أو الزر المختصر).
2. راجع معاينة الرسوم/المديونية إن وُجدت.
3. حدّد حالة الجهاز (**سليم** / **معطل**) إن ظهرت.
4. اضغط **إكمال الاسترجاع**. الجهاز يعود للمخزون وقد يُنشأ أمر دفع.
5. الاسترجاع على عقد **قيد المراجعة** يُرفض — اعتمد العقد أولاً.

### استبدال

1. جهّز **وحدة بديلة متاحة** في نفس الفرع.
2. اختر **استبدال**.
3. اختر الوحدة الجديدة.
4. اضغط **إكمال الاستبدال**. يتحدث بند الجهاز ويُسجَّل الاستبدال في قائمة المشاكل.
5. قد يُسمح بالاستبدال أثناء انتظار المراجعة حسب التصميم الحالي، بخلاف الاسترجاع.

### إلغاء التعاقد

1. اختر **إلغاء التعاقد** (عقد معتمد **قبل** تنفيذ التركيب).
2. اكتب السبب ثم أكمل الخطوات.
3. في الخطوة الأخيرة:
   - يظهر مبلغ **المقدم المستحق للرد** إن وُجد.
   - اختر وجهة الرد: **نقدي** أو **حساب تحصيل**.
   - فعّل تأكيد: «أؤكد أن العميل استلم مبلغ المقدم».
   - اضغط **إكمال إلغاء التعاقد**.
4. إذا لم يوجد مقدم، يكفي الإكمال بدون رد مبلغ.
5. بدون تأكيد الرد أو بدون وجهة عند وجود مقدم يُرفض الإكمال.

### ماذا يحدث بعد إكمال الإلغاء؟

- حالة العقد تصبح **ملغى**.
- مهمة الفني تُلغى.
- الجهاز يرجع للمخزن ويصبح متاحاً.
- يُسجَّل رد المقدم كحركة استرداد (إن وُجد مقدم).

### لو الزر غير ظاهر أو الإجراء مرفوض

- **«تحويل للمشاكل غير متاح لحسابك»**: اطلب من الأدمن صلاحية إدارة مشاكل العقد.
- العقد ما زال **قيد المراجعة**: يجب اعتماده أولاً.
- العقد ليس **ساري**: المعالج للعقد النشط فقط.
- **بعد التركيب**: اختر **استرجاع** وليس إلغاء.

## 10. المخزون

### متى تستخدمها

عند استلام أجهزة، توزيعها على الفروع، متابعة حركة الوحدات، أو تجهيز الإكسسوارات للبيع.

### من القائمة

**المخزون**

- مخزون GPS (`/inventory`)
- مخزون الفرع (`/inventory/branch`)
- حركات الأجهزة (`/inventory/movements`)
- تسجيل مخزون (`/inventory/add`)
- توزيع المخزون (`/inventory/transfers`)

### تسجيل مخزون أجهزة

1. من **المخزون ← تسجيل مخزون**.
2. اختر المخزن/الإدارة حسب الشاشة.
3. أدخل بيانات الوحدات (IMEI / سيريال / أسعار حسب الحقول).
4. احفظ — تظهر الوحدات كمتاحة للبيع بعد التوزيع إن لزم.

### توزيع على فرع واسترجاع مخزون

1. من **المخزون ← توزيع المخزون**: المصدر والوجهة والوحدات ثم أكّد النقل.
2. من **المخزون ← استرجاع مخزون**: إعادة الوحدات للمخزن المركزي/الإدارة حسب الإجراء.

### حركات الأجهزة

1. من **المخزون ← حركات الأجهزة** أو **حركة جديدة** (`/inventory/movements/new`).
2. سجّل تسليم/استلام بين فروع أو موظفين.
3. يصل إشعار للمستلم. افتح الحركة من الجرس أو من القائمة ثم **أكّد** أو **ارفض**.
4. إلى أن يُؤكَّد الاستلام تبقى الحركة معلّقة.

### المخازن وإعدادات المنتج

- **المخازن:** أنشئ مخازن واربطها بالفرع/الإدارة قبل التسجيل والتوزيع.
- **إعدادات المنتج:** أسعار وأصناف أجهزة الشركة وأسعار **خارج الشركة — جهاز خارجي** المستخدمة في POS.

### الإكسسوارات (سلسلة البيع)

1. أضف الأصناف من **كتالوج الإكسسوارات** (الاسم والسعر).
2. اجمع باكدجات من **باكدجات الإكسسوارات** إن بِعتم مجموعات.
3. أدخل الكميات في **مخزون الإكسسوارات** على المخزن الصحيح.
4. البيع اليومي من **قسم التعاقدات ← بيع إكسسوارات**.

### ملاحظات

- لا تبع وحدة غير موجودة في المخزن المختار في شاشة POS.
- الاسترجاع (المخزون) يعيد الوحدات للمخزن المركزي/الإدارة حسب الإجراء، وهو غير **استرجاع العقد** من قسم المشاكل.

## 11. المبيعات (CRM)

مجموعة القائمة اسمها **المبيعات** — وهي وحدة الترشيحات والمتابعات (ليست شاشة POS).

### متى تستخدمها

لتسجيل ومتابعة ترشيحات العملاء (إحالات) وتقارير الأداء.

### من القائمة

**الرئيسية**

- خط الترشيحات (`/crm/referrals`)
- قائمة الترشيحات (`/crm/referrals/list`)

**العمل اليومي**

- المهام (`/crm/tasks`)
- سجل المكالمات (`/crm/call-logs`)
- الأنشطة (`/crm/activities`)

**التحليلات**

- تقارير الترشيحات (`/crm/reports`)
- أداء الموظف (`/crm/reports/owner-detail`) و`/crm/reports/owners/{رقم}`
- لوحة المتصدرين (`/crm/reports/leaderboard`)
- شبكة الإحالات (`/crm/referrals/network`)
- خط الأنابيب (`/crm/reports/owner-pipeline`)
- لوحة المدير (`/crm/ceo`) — الصفحة الافتراضية لبعض حسابات الأدمن

إضافة ترشيح: `/crm/referrals/add`. ملف الترشيح: `/crm/referrals/{رقم}`.

### تسجيل ترشيح

1. من **المبيعات ← خط الترشيحات** أو **قائمة الترشيحات**.
2. أضف ترشيحاً جديداً مع رقم الهاتف والاسم ومصدر الإحالة إن طُلب.
3. على اللوحة: اسحب البطاقة بين الحالات أو حدّث الحالة (لا يرد، غير مهتم، جدولة تركيب، …). فلتر حسب الموظف إن لزم.
4. عند الوصول لمراحل معيّنة قد يُنشأ **عميل** مرتبط تلقائياً.

### المتابعات والتقارير

- **سجل المكالمات** و**المهام** و**الأنشطة**: متابعة الاتصال والعمل اليومي. عند تسجيل مكالمة يمكن اختيار **ترشيح** من بحث جهة الاتصال لربط المكالمة به.
- **تقارير الترشيحات**: ملخص الأداء حسب الفترة؛ اضغط اسم الموظف لفتح تقريره التفصيلي.
- **ملف الترشيح**: من لوحة الترشيحات أو من تقرير الموظف، افتح «عرض الملف» لرؤية بيانات الترشيح وسجل التعاملات.
- **شبكة الإحالات**: شجرة من رشّح من.
- **لوحة المدير** و**خط الأنابيب** و**لوحة المتصدرين**: نظرة إدارية (قمع، تركيبات، متابعات، أهداف).

### ملاحظات

- ترشيح بدون مصدر إحالة صالح قد يُرفض.
- حالة «لا يرد» غالباً تتطلب تاريخ متابعة.
- تسجيل العملاء المباشرين للفرع يبقى من بند **العملاء** وليس من CRM.
- صلاحيات CRM قد تقيّد الموظف بترشيحاته فقط (`access_own_leads`).

2. اضغط موظف جديد.
3. أدخل البيانات والفرع والقسم والراتب ورقم البصمة إن وُجد.
4. اختر ربط حساب مستخدم (تلقائي / ربط موجود / بدون حساب) حسب الخيارات الظاهرة.

1. عرّف **الوظائف** و**الورديات** و**أنواع الإجازة** و**العطلات** و**البدلات** قبل التشغيل اليومي.

3. **الإجازات:** الموظف/الموارد تقدّم طلباً؛ الموارد تعتمد أو ترفض.
4. **أهداف المبيعات:** حدّد أهداف الفترة وتابع الإنجاز من الملف الشخصي أيضاً.
5. **مسيرات الرواتب** ثم **الرواتب:** أنشئ مجموعة، راجع الاستحقاقات والخصومات، ثم اعتمد المسير.

### أجهزة البصمة

- مزامنة أجهزة البصمة من شاشة أجهزة البصمة بعد ضبط الجهاز والفرع.
- بعد تسجيل البصمة على جهاز فرع، استخدم **سحب البصمات وتوزيعها** لنسخها لنفس رقم الموظف على أجهزة الفروع الأخرى (وضع ADMS).

تفاصيل أعمق متوفرة أيضاً في ملف [`docs/HRM.md`](HRM.md) للفريق التقني/الإداري.

**الآعدادات ← المساعدة** (`/help/faq`)

- تصفّح الأسئلة حسب التصنيف (تعاقدات، تحصيل، مخزون، …).

### المساعد الذكي (الشات)

- زر المساعدة/الشات أسفل الشاشة (حسب الواجهة).

### الجولات التعريفية (Tour)

- في بعض الصفحات (لوحة التحكم، تعاقد جديد، التعاقدات، CRM، الموارد البشرية، المحاسبة، التقارير) يوجد زر لبدء جولة قصيرة على عناصر الشاشة.

### الرسائل والملاحظات

- **الآعدادات ← ملاحظات المستخدمين** (`/admin/feedback`) للأدمن لمراجعة ما أرسله الموظفون.

## 16. بوابة العميل

واجهة منفصلة للعميل النهائي (ليست حساب موظف). تسجيل الدخول: `/portal/login` بحساب من نوع بوابة العميل.

الموظف ينشئ/يربط حساب البوابة من مسار CRM/العملاء حسب الصلاحية. المحصّل يمكنه إيقاف الدخول عبر **رسيت متأخر**.

### من قائمة البوابة (الظاهرة)

- **لوحة التحكم** (`/portal`) — الرصيد المستحق، آخر الفواتير، جدول الفواتير الأخيرة (رقم، تاريخ، إجمالي، رصيد، حالة)
- **الفواتير** (`/portal/invoices`) — قائمة فواتير مع ترقيم صفحات
- **كشف الحساب** (`/portal/ledger`) — سجل الدفعات (تاريخ، فاتورة، مبلغ)
- **تسجيل الخروج**

### طلبات الشراء (غير ظاهرة في القائمة)

المسار `/portal/order-requests` موجود في النظام لكنه **غير مربوط** في الشريط الجانبي للبوابة. إن فُتح بالرابط مباشرة: يمكن إرسال ملاحظات طلب شراء ومراجعة الطلبات السابقة.

لا توجد في البوابة حالياً: خريطة تتبّع، تذاكر دعم، أو صفحة ملف شخصي في الواجهة (حتى إن وُجد مسار API للملف).

## 17. أسئلة شائعة عامة

**كيف أختار الفرع؟**  
من الشريط العلوي — القائمة المنسدلة للفرع. اختره قبل التعاقد أو التحصيل.

**أين مهمة اليوم؟**  
البند الأول في القائمة للمبيعات: **مهمة اليوم**.

**كيف أعمل تعاقداً جديداً؟**  
قسم التعاقدات ← تعاقد جديد. اختر نوع الخدمة والعميل والجهاز وطريقة الدفع ثم احفظ.

**ما الفرق بين أنواع الخدمة الأربعة؟**  
تعاقد جديد = جهاز من المخزون. تجديد اشتراك = تجديد جهاز موجود. جهاز خارج الشركة = سيريال يدوي. نقل ملكية = عميل جديد لنفس الجهاز.

**كيف أبيع إكسسوارات؟**  
جهّز الكتالوج والمخزون من مجموعة المخزون، ثم قسم التعاقدات ← بيع إكسسوارات.

**أين تعاقداتي؟**  
زر **تعاقداتي** أعلى شاشة POS (وليس في الشريط الجانبي) يفتح `/invoices/mine`.

**كيف أضيف عميلاً؟**  
بند **العملاء** ← إضافة. الاسم والهاتف مطلوبان.

**كيف أحصّل قسطاً؟**  
قسم الاقساط ← تحصيل الأقساط. ابحث عن العميل ثم سجّل الدفعة (نقدي / محفظة / انستا / تحويل بنكي).

**كيف أشوف تاريخ السداد وطريقة الدفع لكل قسط؟**  
في تحصيل الأقساط اضغط **عرض جميع الأقساط** على التعاقد. العمودان يظهران في هذا الجدول فقط؛ غير المسدد يظهر `—`.

**حُذف قسط بالغلط، أرجّعه منين؟**  
الآعدادات ← سلة المهملات ← فلتر **قسط** ← **استرجاع**. يحتاج صلاحية مدير (عرض/استعادة المهملات). لا يوجد حذف أو استرجاع من شاشة التحصيل.

**أين سجل المدفوعات؟**  
قسم الاقساط ← سجل المدفوعات.

**كيف أراجع تعاقداً؟**  
المراجعة ← مراجعة التعاقدات ← اعتماد أو رفض. يمكن فلترة نوع الخدمة.

**كيف ألغي تعاقداً؟**  
تحويل للمشاكل ← إلغاء التعاقد. مسموح فقط قبل تنفيذ التركيب، ويتطلب صلاحية إدارة مشاكل العقد. بعد التركيب استخدم **استرجاع**.

**كيف أسترجع أو أستبدل جهازاً؟**  
تحويل للمشاكل ← استرجاع أو استبدال. للاستبدال يلزم وحدة بديلة متاحة في الفرع.

**أين قائمة المشاكل المفتوحة؟**  
قسم المشاكل ← قائمة المشاكل.

**كيف أسجّل مخزوناً؟**  
المخزون ← تسجيل مخزون، ثم وزّع على الفروع من توزيع المخزون عند الحاجة.

**كيف أؤكّد حركة جهاز؟**  
من إشعار الجرس أو المخزون ← حركات الأجهزة ← تفاصيل الحركة ← تأكيد أو رفض.

**كيف أضيف مستخدماً؟**  
الآعدادات ← المستخدمون ← مستخدم جديد (مع الدور والفرع).

**كيف أضيف موزعاً؟**  
بند **الموزعين** ← موزع جديد.

**أين الترشيحات؟**  
مجموعة **المبيعات** ← خط الترشيحات أو قائمة الترشيحات.

**أين بوابة العميل؟**  
رابط `/portal/login` للعميل النهائي. الموظفون يستخدمون النظام الرئيسي.

**أين المساعدة داخل النظام؟**  
الآعدادات ← المساعدة، أو استخدم زر الشات أسفل الشاشة، أو الجولة التعريفية في الصفحة.

**لماذا لا أرى قائمة معيّنة؟**  
صلاحيات دورك لا تشملها. اطلب من مدير النظام تعديل الدور أو الصلاحيات.

**نسيت كلمة المرور**  
تواصل مع مدير النظام لإعادة التعيين (حسب سياسة الحسابات لديكم).
